# Playwright E2E Testing

## Purpose

Playwright is used to validate critical user workflows in CostaSpanish LMS
through a real browser.

Initial coverage focuses on:

- Teacher authentication
- Student management
- Course management
- Lesson creation and editing
- Lesson completion and voucher consumption
- Resource management

## Requirements

- Node.js
- Project dependencies installed
- Playwright Chromium browser installed
- Required local environment variables

## Installation

```bash
npm install
npx playwright install chromium
```
